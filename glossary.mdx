---
title: "Glossary"
description: "The words Polywatcher uses."
---

| Term | Meaning |
|---|---|
| Long | A position that gains when the price rises. Rows show it as LONG. |
| Short | A position that gains when the price falls. Rows show it as SHORT. |
| Open | An order that opened a position or added to one. Rows show it as OPEN in blue. |
| Close | An order that closed part or all of a position. Rows show it as CLOSE in magenta. |
| Buy | An order that bought. Shown only when the position it changed is not known yet. |
| Sell | An order that sold. Shown only when the position it changed is not known yet. |
| Value | An order's size in dollars. |
| Size | A quantity of the asset itself, for example 2.5 ETH. |
| Whale order | An order of \$10K or more. |
| Liquidated | A position closed by force because the account fell below its margin. |
| P&L | Profit and loss. On the leaderboard, after fees. |
| Account value | What an account holds, including open positions at their current price. |
| Leverage | Position value divided by the margin it uses. |
| Identifying | The wallet behind an order is not known yet. |
| Stocks | Markets on single company shares, such as NVDA and AAPL. |
| Crypto | Markets on crypto assets, such as BTC and ETH. |
| Commodities | Markets on gold, silver and oil. |
| Indexes | Markets on stock indexes and baskets, such as the S&P 500 and Nasdaq 100. |
